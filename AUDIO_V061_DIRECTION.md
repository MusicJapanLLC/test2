# OLD GUILD∞ v0.6.1 — Audio direction

Audio lane only

## User direction
Keep improving BGM and system feel in parallel with movement

## BGM target
- Cologne / medieval folk / tavern atmosphere
- comfortable for long play sessions
- not bombastic, not busy
- warm wood / strings / plucked textures / restrained percussion feel
- subtle loop variation so 5-10 minutes does not feel obviously repetitive

## Required system behavior
- user gesture unlock only; no blocking start screen
- BGM fade in: ~1.2-2.0s
- BGM fade out / mute: ~0.5-0.9s
- scene/mood changes crossfade rather than hard cut
- FEVER may add a light rhythmic layer without replacing the whole track
- movement/step SFX should be very quiet and rate-limited during continuous movement
- menu open/close SFX short and soft
- gain balance for iPhone speaker first

- input
- UI/Typography
- graphics
- economy/NPC count
- ChatGPT Work new game
