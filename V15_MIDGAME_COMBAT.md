# GUILD∞ v1.5 — MIDGAME / COMBAT / ECONOMY

Updated: 2026-10-04 JST
Scope: old/legacy GUILD∞ only

Latest owner feedback:
- difficulty is far too easy
- progression depth is too shallow
- attack / damage / death effects are needed
- enemies feel like toys and need real movement
- more building types are needed: Guild Hall, Watchtower, etc.
- resource collection has inflated badly by Day 5
- raise progression ceilings

v1.5 goals:
1. make Day 3–7 require real defense decisions
2. reduce runaway resources with storage caps, upkeep, lower worker yields, and more sinks
3. add Guild Hall / Watchtower / Warehouse / Barracks
4. add Rank E→S and level caps tied to rank
5. extend Hut to Lv5 and Palisade to Lv6
6. add Walker / Runner / Brute / Spitter enemy archetypes
7. add attack slash, projectile, damage-number, hit-flash, knockback-lite, and death dissolve effects
8. keep zero screen shake
9. preserve smooth drag, outside gathering, inside construction, autosave, original BGM

Midgame loop:
OUTSIDE GATHER -> STORAGE LIMIT -> BUILD/UPGRADE -> RANK UP -> STRONGER NIGHT -> DAMAGE/REPAIR -> EXPAND -> NEW BUILDINGS

Economy principles:
- base storage is limited
- Warehouse raises caps
- workers consume FOOD daily
- ordinary workers gather much slower than v1.4
- high-level structures become the major resource sinks
- over-cap resources are not banked forever

Combat principles:
- first night is survivable but visible
- Day 3 introduces Runner
- Day 5 introduces Brute
- Day 7 introduces Spitter
- Watchtower fires projectiles automatically
- Barracks strengthens Guards
- intact wall must still block entry
- no camera shake
