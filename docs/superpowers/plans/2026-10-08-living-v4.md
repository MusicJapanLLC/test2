## Global Constraints
- Only World edition behavior changes; existing Chief, Pocket and v1.6 remain compatible
- Preserve existing World save namespace and validate additive fields; never silently reset progress
- Keep four-gate routing, no wall auto-arrows, 16 maximum towers, expedition identity and roster serialization
- Player harvest credits immediately; workers only credit actual deposits; cargo survives storage-full, reload, role change, night and expeditions without duplication
- No camera shake, no speed toggle, no audio toggle; audio unlocks on existing user gesture
- Same pixel font, phone-first readable labels and 44px minimum controls; prevent chat/FX overload
- One ambient conversation pair at a time; no paid random rewards or actual checkout activation
- Publish only a narrowly scoped /mayor/ route, preserving existing root and /the-world/
